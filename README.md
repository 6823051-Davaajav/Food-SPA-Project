# Food Composition SPA — 2.1–2.5

Номын 2.1–2.5-д тулгуурласан өөрчилсөн сургалтын жишээ. Vanilla JavaScript, hash router, тусдаа pages, reusable layout, navbar, MN/EN i18n.

## Ажиллуулах
VS Code → `src/index.html` → **Open with Live Server**, эсвэл төслийн үндсэн хавтаснаас `python -m http.server 8000 --directory src` ажиллуулаад `http://localhost:8000` руу орно.

## Турших
`#/overview`, `#/search`, `#/calculation`, `#/books`, `#/contact`, `#/unknown` хаягуудаар орж шалгана. 🌐 товч дарж хэл солих, refresh хийсний дараа хэл хадгалагдахыг шалгана.

**Тайлбар:** 2.1–2.5 нь суурь бүтэц тул бодит хүнсний өгөгдлийн хайлт, тооцоолол одоогоор хийгдээгүй. GitHub руу хэрэглэгч өөрөө push хийнэ.
