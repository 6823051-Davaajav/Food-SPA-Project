# Монгол хүнсний найрлага — Food Composition SPA

## Төслийн танилцуулга

Монгол хүнсний найрлага (Mongolian Food Composition) нь хүнсний бүтээгдэхүүний шим тэжээлийн мэдээллийг хайх, харах, сонгосон хэмжээгээр тооцоолох зориулалттай Single Page Application (SPA) веб сайт юм.

Энэхүү төсөл нь HTML, CSS, JavaScript ашиглан боловсруулагдсан бөгөөд Монгол болон Англи хэлний сонголттой.

## Веб сайтын холбоос

https://6823051-davaajav.github.io/Food-SPA-Project/

## Үндсэн боломжууд

1. **Overview (Тойм)** — Системийн танилцуулга.
2. **Search (Хайлт)** — Хүнсний бүтээгдэхүүнийг нэрээр хайж, илчлэг, уураг, өөх тос, нүүрс усны мэдээллийг харах.
3. **Calculator (Тооцоолуур)** — Хүнсний бүтээгдэхүүн болон граммын хэмжээг сонгон шим тэжээлийн үзүүлэлтүүдийг тооцоолох.
4. **Books (Ном)** — Хүнс, хоол тэжээлийн чиглэлийн жишиг материалуудын жагсаалт.
5. **Contact (Холбоо барих)** — Хэрэглэгчийн санал хүсэлтийг формоор шалгах.
6. **Language (Хэлний сонголт)** — Монгол болон Англи хэлээр ашиглах.

## Ашигласан технологи

- HTML5
- CSS3
- JavaScript (ES Modules)
- Hash-based Routing
- GitHub
- GitHub Pages

## Төслийн бүтэц

- `src/index.html` — Веб сайтын үндсэн HTML
- `src/css/` — Загвар, дизайн
- `src/js/app.js` — Программын үндсэн логик
- `src/js/router.js` — Хуудас хоорондын чиглүүлэлт
- `src/js/pages/` — Тусдаа хуудсууд
- `src/js/components/` — Дахин ашиглах компонентууд
- `src/js/i18n/` — Монгол, Англи хэлний тохиргоо
- `src/js/services/` — Хүнсний мэдээлэл боловсруулах үйлчилгээ
- `src/data/` — Хүнсний жишиг өгөгдөл

## Туршилтын үр дүн

- Хуудас хооронд шилжих ажиллагааг шалгасан.
- Монгол болон Англи хэл солих боломжийг шалгасан.
- Хүнсний хайлтын хүснэгт мэдээлэл харуулж байгааг шалгасан.
- Тооцоолуурын үр дүнг 200 грамм сүүний жишээгээр шалгасан.
- Холбоо барих формын баталгаажуулалт болон мэдэгдлийг шалгасан.
- GitHub Pages дээр веб сайтыг ажиллуулсан.

## Анхаарах зүйл

Хүнсний мэдээлэл нь төслийн жишиг өгөгдөл юм. Холбоо барих форм нь мэдээллийг шалгаж, мэдэгдэл харуулдаг бөгөөд сервер эсвэл имэйл рүү бодитоор илгээдэггүй.
