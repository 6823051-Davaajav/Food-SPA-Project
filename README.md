
# Food Composition SPA — Даалгавар 2 (2.6–2.9)

## Төслийн танилцуулга

Энэхүү төсөл нь хүнсний найрлагын мэдээллийг
харуулах, хайх, шүүх зориулалттай Single Page
Application (SPA) веб систем юм.

Даалгавар 2-ын хүрээнд номын 2.6–2.9 хэсгийн
дагуу системийн боломжуудыг өргөжүүлсэн.

## Хэрэгжүүлсэн боломжууд

- Монгол, Англи хэлний дэмжлэг
- Хүнсний нэрээр хайх
- Хүнсний бүлгээр шүүх
- Хүнсний дэлгэрэнгүй мэдээлэл харах
- Илчлэг, уураг, өөх тос, нүүрс ус харуулах
- Хайлтын тохиргооны checkbox
- Collection Information хүснэгт
- Хүнсний зургийг томруулан харах modal
- JSON өгөгдөл боловсруулах
- Хуудсууд хооронд шилжих hash router

## Жишээ өгөгдөл

Системд 3 хүнсний мэдээлэл ашигласан:

1. Сүү (Milk)
2. Үхрийн мах (Beef)
3. Цагаан будаа (White rice)

## Ажиллуулах заавар

1. Төслийг VS Code дээр нээнэ.
2. `src/index.html` файлыг нээнэ.
3. Open with Live Server сонгоно.
4. `#/search` хуудас руу орно.

## Туршилт

- Хүнсний нэрээр хайлт хийх
- Хүнсний бүлгээр шүүх
- Дэлгэрэнгүй мэдээлэл харах
- Collection Information сонгох
- Монгол, Англи хэл солих
- Хуудсыг шинэчилж хэл хадгалагдахыг шалгах

## Ашигласан технологи

- HTML5
- SCSS / CSS
- Vanilla JavaScript
- JSON
- Node.js
- Git, GitHub

## Дүгнэлт

Даалгавар 2-ын хүрээнд хүнсний мэдээллийн SPA
системийг өргөжүүлж, хоёр хэлээр хайлт хийх,
хүнсний бүлгээр шүүх, шим тэжээлийн болон
цуглуулсан мэдээллийг хүснэгтээр харуулах
боломжуудыг хэрэгжүүлсэн.

Цаашид хүнсний мэдээллийн санг өргөжүүлж,
нэмэлт үзүүлэлтүүдийг оруулах боломжтой.
